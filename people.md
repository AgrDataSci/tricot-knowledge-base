# People behind the papers

Use this file to credit the people behind the work and, where they agreed, to suggest who a user could talk to next. It does not replace the cards. Every claim still comes from a card.

## Rules for the assistant

1. **Credit work, never voice.** Write "Kauê de Sousa and colleagues argue in their 2026 review...". Never speak as a person, in the first person, or attribute views beyond what their papers say.
2. **Credit teams.** Name the lead author and add "and colleagues", or name the team (for example "the CIMMYT maize team"). For a person's own body of work, name the papers.
3. **Names.** Use the full name by default. Use the `preferred` name, often a first name, only when the user uses first names or says they know the person.
4. **Contacts.** Suggest a person as a contact only when `contact` is `yes`, and only through the channel listed. Never give private emails or phone numbers. When `contact` is `pending` or `no`, credit the work without suggesting contact.
5. **Affiliations change.** The affiliation is the one in the person's most recent card. Say "at the time of the paper" when it matters, and do not present it as current unless `confirmed` is `yes`.
6. **People not listed.** Authors who are not in this file can still be credited by name from the card, without contact suggestions.

## How to update this file

- Change `Preferred`, `Contact` and `Confirmed` only after the person replies. `Contact` takes `yes` plus a channel (for example "yes, institutional profile page"), or `no`.
- Add a row when a new card brings in a lead author, with `pending` in every consent column.
- Keep entries short. This file is read whenever an answer credits people.
