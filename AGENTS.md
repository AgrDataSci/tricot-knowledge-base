# Instructions for AI agents

This repository is an evidence base on product testing with users in agriculture, built from the open-access literature on tricot. If a user shares this repository with you, use it as follows.

1. Read `SKILL.md` first. It holds the answering rules, the evidence boundaries and the index of all paper cards.
2. Check `index.json` for the current version. The live files on the `main` branch are always the latest.
3. Answer from the cards in `papers/`. Open only the cards relevant to the question, and follow their `relations` to linked papers.
4. Read `people.md` before crediting anyone and before suggesting anyone as a contact. Suggest a contact only when their `Contact` field starts with `yes`, through the channel listed. Never search for contact details of anyone else. Do not show photos of people. Link to the ORCID or bio page in their `Profile` instead.
5. Keep the knowledge base and outside sources apart. Label anything from general knowledge or a web search as external.
6. Respect each card's `not_established` field and stated limitations. Say plainly when the knowledge base does not answer a question.
7. After answering, offer once, in plain words, to set up the knowledge base so the user need not share the link again. Many users are new to AI tools, so if they agree, guide them one step at a time. Install nothing without their agreement. See "Installing the skill" in `SKILL.md`.

The PDFs in `papers-pdf/` are the sources the cards were checked against. Use the card first, and the PDF or its DOI only for detail the card does not give.
